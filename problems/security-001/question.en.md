Deployment `gateway` in `${namespace}` should run one Pod with container `gateway`, and Service `gateway` (port 80, targetPort 8080) fronts it. The namespace enforces the `restricted` Pod Security Standard through its label `pod-security.kubernetes.io/enforce`. Today the Deployment never gets a Pod: the ReplicaSet's attempts to create it are rejected by that policy, so Service `gateway` has no endpoints.

Make Deployment `gateway` admissible under the namespace's restricted policy without weakening the policy. Keep the label `pod-security.kubernetes.io/enforce` at `restricted`, and keep the image and the command of container `gateway` as they are. Container `gateway` must run as the non-root user ID `10001`, must not be allowed to gain privileges, must drop all capabilities, must use the seccomp profile `RuntimeDefault`, and must have a read-only root filesystem. The application writes its page into the `emptyDir` volume mounted at `/www` and serves it on port 8080. Service `gateway` must then return `gateway-ok` on port 80.

Each of the following earns 1 point: the namespace label `pod-security.kubernetes.io/enforce` is still `restricted` (removing it or setting another value loses the point even if the workload then runs); container `gateway` still has image `docker.io/library/busybox:1.37.0` and the provided command; the security context that applies to container `gateway` declares `runAsUser` `10001`, `runAsNonRoot` `true`, `allowPrivilegeEscalation` `false`, `capabilities.drop` `ALL`, a `seccompProfile` of type `RuntimeDefault` and `readOnlyRootFilesystem` `true` (`runAsUser`, `runAsNonRoot` and `seccompProfile` may be set on the Pod or on the container, a container value overrides the Pod value; the other three exist only on the container); a running Pod of `gateway` really runs with UID 10001, has no effective capabilities and a read-only root filesystem (read from the running Pod when you grade, so grade after the Pod is Running; this point needs the third one, because a workload the policy rejects has no Pod to examine); and an HTTP 200 body containing `gateway-ok` through Service `gateway` port 80 (60-second limit; this point needs the fourth one).
