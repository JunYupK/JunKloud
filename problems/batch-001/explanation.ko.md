Job의 suspend를 해제하고 완료 상태와 실제 worker 로그를 확인합니다. CronJob은 매분 실행, suspend false, Forbid, 성공·실패 이력 각 1개로 구성합니다. */1과 *는 같은 매분 스케줄입니다. 수동 Job을 만들더라도 예약 실행 점수는 얻지 못하며 컨트롤러가 관찰 시작 후 실제 Job을 생성해야 합니다.
 예약 Job은 관찰 시작 후 새로 생성되어 같은 90초 안에 성공 완료해야 합니다. 생성만 되었거나 실패한 예약 Job은 정답이 아니며, 실패 상태는 FAIL, 관찰 불가나 원인 불명 지연은 ERROR입니다.
